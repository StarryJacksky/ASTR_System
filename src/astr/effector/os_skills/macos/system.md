⚠️ 本指南尚未在真机验证（ASTR 的 mac backend 计划 P6 随 M5 Max 落地）。
知识来自通识，使用时保持怀疑：第一次做某操作后必须截图确认效果。

操作节奏：看清楚 → 动一下 → 看结果。同一动作两次无效就换做法。

基础对应关系（Windows→macOS）：ctrl→cmd。复制/剪切/粘贴 cmd+c / cmd+x（Finder
里剪切移动用 cmd+c 复制后 cmd+opt+v"移动到此处"）/ cmd+v；撤销 cmd+z。

窗口与对话框：关窗口 cmd+w，退出应用 cmd+q（慎用）。对话框 enter=默认钮，esc=取消。
菜单栏在屏幕顶部（不在窗口内）——应用的功能都从顶部菜单栏找。

Finder（文件管理）：新建文件夹 cmd+shift+n；重命名=选中后按 enter（和 Windows 的
F2 相反，enter 是改名不是打开）；打开=cmd+o 或双击；回上级 cmd+↑。

Spotlight 搜索：cmd+space 呼出，输入应用名回车可启动任意应用——找不到入口时的万能门。
