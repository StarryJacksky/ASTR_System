- ctrl+shift+n（新建文件夹快捷键）在资源管理器里完全无效，按了没有任何反应。
  不要尝试、不要重试——建文件夹只用按钮或右键菜单。
- Alt 键提示序列（按 alt 后按字母操作功能区）同样无效，不要用。
- 屏幕 2560×1440。资源管理器功能区的"新建文件夹"按钮位于窗口最大化时
  左上方约 (18%, 6%) 处，金色文件夹图标、字分两行。
