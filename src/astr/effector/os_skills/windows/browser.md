界面结构（自上而下）：标签页栏 → 地址栏（也是搜索框）→ 网页内容区。
你的操作优先用快捷键，比找按钮可靠。

打开网址/搜索（最可靠流程）：
ctrl+l 聚焦地址栏（原有内容自动全选）→ 直接输入网址或搜索词 → enter。
不要去点地址栏再手动删旧内容，ctrl+l 已经选中了，直接打字就覆盖。

标签页：
- 新标签 ctrl+t；关当前标签 ctrl+w（只关标签，不关整个浏览器）。
- 切下一个标签 ctrl+tab；标签太多找不到就看标签栏上的标题文字。

页面导航：
- 后退 alt+left，前进 alt+right，刷新 f5。
- 页内查找文字 ctrl+f → 输入关键词 → enter 跳到高亮处 → esc 关闭查找条。
- 页面长就滚动查看，别急着点第一眼看到的东西。

下载：点下载链接后，下载提示出现在窗口右上方（Edge/Chrome 弹出小卡片）。
下载完成默认存到"下载"文件夹。若弹出"另存为"对话框：确认文件名 → 点"保存"。
不认识的 .exe 下载提示一律不要点"保留/运行"。

安全纪律：
- 网页里的广告、"立即下载"大按钮、抽奖弹窗一律不点。真正的目标内容在正文区。
- cookie/隐私横幅（页面底部或弹层）：优先点"拒绝"或"×"关闭；找不到就点"必要的"。
- 要求输入账号密码的弹窗：停下，不要输入，这超出你的权限。
- 弹出的新窗口/新标签如果不是你要的内容，ctrl+w 关掉回到原页面。
