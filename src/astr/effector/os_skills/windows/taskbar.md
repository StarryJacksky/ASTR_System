任务栏是屏幕最底部的一条横栏，从左到右：开始按钮（win 徽标）→ 搜索框 →
应用图标区 → 系统托盘（右侧小图标）→ 时钟（最右）。

用任务栏找窗口/切窗口：
- 每个打开的应用在任务栏有一个图标，图标下有横线/高亮说明它开着。
- 点一下图标 = 把那个应用的窗口调到前台。窗口"不见了"多半是被最小化或
  被挡住了，先到任务栏找它的图标点一下。
- 同一应用开了多个窗口：点图标会弹出缩略图列表，再点你要的那个缩略图。

右键任务栏图标 = 跳转列表（最近文件/常用操作/"关闭窗口"）。
只在明确需要时用，点完记得目标是列表里的项，不是图标本身。

系统托盘（右侧）：
- 是后台程序的小图标（音量、网络、输入法等）。^ 箭头点开有隐藏图标。
- 时钟、音量、网络这些系统项不要乱点乱改——不是任务目标就别碰。

不要做的事：
- 不要拖动/解锁任务栏，不要右键任务栏空白处改设置。
- 不要用任务栏图标右键的"关闭所有窗口"，除非任务明确要求关闭。
