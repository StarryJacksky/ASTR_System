启动一个应用的最可靠方式（照这个顺序做，不要自己发明别的路）：
1. 按 win 键 → 开始菜单弹出。
2. 直接打字输入应用名（如"记事本"或 notepad）——不用先点任何搜索框，
   开始菜单打开后打字就自动进入搜索。
3. 看搜索结果：最上方"最佳匹配"就是第一个结果。确认名字对 → 按 enter 打开。
4. 名字不对就继续输入更完整的名字，或按 esc 关闭重来。

注意事项：
- 输入应用名用英文名最稳（notepad、chrome、cmd），避免输入法干扰。
- enter 打开的是第一个结果。如果第一个结果不是目标，用鼠标点正确的那一项。
- 按错了或菜单里迷路了：esc 关闭开始菜单，回到桌面，重新按 win 再来。
- 开始菜单里的磁贴/推荐内容不要乱点，只用搜索这一条路。
- 应用启动需要几秒，按完 enter 等窗口出现，别重复启动第二次。
