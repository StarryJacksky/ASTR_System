记事本是纯文本编辑器：一个大白色编辑区 + 顶部菜单栏（文件/编辑/格式/查看/帮助）。
点编辑区任意位置出现光标后直接打字即可，没有格式、没有按钮。

写入文字：点一下编辑区确保光标在里面 → 打字。换行按 enter，撤销 ctrl+z。
全选 ctrl+a，复制 ctrl+c，粘贴 ctrl+v。

保存（首次保存有对话框，照剧本走）：
1. 按 ctrl+s。
2. 若这是新文件，会弹"另存为"对话框：
   - 下方"文件名(N)"输入框里默认是"*.txt"或"无标题"，处于选中状态，
     直接输入目标文件名（覆盖旧内容）。
   - 不要动上方的文件夹导航区，默认保存位置就行（除非任务指定路径）。
   - 点右下角"保存(S)"按钮。
3. 保存成功的标志：窗口标题从"无标题 - 记事本"变成"文件名 - 记事本"，
   且标题里没有 * 号。
4. 已保存过的文件再按 ctrl+s 直接存，不弹任何框。

关闭时的三键对话框：内容未保存就关窗口，会弹"是否将更改保存到 ×××？"，
三个按钮：保存(S) / 不保存(N) / 取消。任务要求保存就点"保存"（可能接着弹
另存为，按上面剧本走）；不确定就点"取消"回到编辑器，先 ctrl+s 存好再关。

坑：文件名输入前确认输入法是英文模式；标题栏带 * 表示有未保存修改。
