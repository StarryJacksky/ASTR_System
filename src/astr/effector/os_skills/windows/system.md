操作节奏：看清楚 → 动一下 → 看结果。每次动作后界面需要片刻反应，别急着连点。
同一个动作做了两次没变化，说明这条路不通，换一种做法，不要第三次。

窗口与对话框：
- 弹出的错误/确认对话框：enter=按默认钮（通常是"确定"），esc=取消关闭。
- 关当前窗口 alt+f4（只在明确要关时用）。不要点最小化/还原按钮——保持窗口现状。
- 弹出菜单（右键菜单/下拉菜单）点开后：点菜单外任意空白处=关闭菜单；esc 也能关。

菜单操作：
- 右键菜单里带▶或"(字母)"的项是子菜单（如"新建(W)"）：点击它后子菜单会在旁边展开，
  下一步要点的是子菜单里的项，位置在原菜单右侧。
- 菜单一次只能点一项；点完菜单就消失了，别再对着原位置点。

输入文本：
- 输入发生在"当前焦点"处。输入前确认有输入框/编辑框在等着（有光标或蓝色选中文本）。
- 输入完按 enter 提交。输错了 esc 取消。

复制/剪切/粘贴：ctrl+c / ctrl+x / ctrl+v；撤销 ctrl+z。这些组合键可靠。
