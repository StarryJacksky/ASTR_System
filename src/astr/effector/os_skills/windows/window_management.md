窗口顶部一条横栏是标题栏：左侧显示窗口标题，右上角三个按钮从左到右是
最小化(—) / 最大化或还原(□) / 关闭(×)。认准标题栏文字确认这是不是目标窗口。

切换窗口（找某个已打开的窗口）：
- 首选 alt+tab：按住 alt 不放，敲 tab 逐个高亮窗口缩略图，高亮到目标时
  松开 alt。窗口少时按一次 alt+tab 就是"回到上一个窗口"。
- 也可以到任务栏点应用图标（见任务栏篇）。
- 找不到窗口时：先看任务栏有没有它的图标，有就点图标；没有说明应用
  没开，要先启动它，而不是在桌面上乱找。

最大化/还原/移动：
- win+up 最大化当前窗口；win+down 还原（再按一次会最小化，慎连按）。
- 移动窗口：按住标题栏中部（避开右上角三个按钮）拖到目标位置松手。
- 窗口太小看不全内容时先 win+up 最大化再操作。

双窗口并排（对照/拖拽文件时用）：
1. 焦点在窗口 A → win+left，A 贴到左半屏。
2. 右半屏会列出其他窗口的缩略图 → 点窗口 B 的缩略图，B 占右半屏。
   （没弹缩略图就切到 B 按 win+right。）

纪律：
- 不要点最小化按钮藏窗口；不要点 × 关窗口，除非任务明确要关。
- 操作前确认目标窗口在最前面（标题栏是亮的）——对着背景窗口点击无效
  且第一下点击只是把它调到前台。
