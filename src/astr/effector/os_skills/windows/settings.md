打开设置：按 win+i（最可靠）。或 win 键 → 输入"设置" → enter。

界面结构：设置首页是一格一格的分类磁贴（系统/设备/个性化/应用……）。
进入分类后变成两栏：左侧窄栏=子分类列表，右侧宽区=具体设置项。

找设置项的最可靠方式——用搜索，不要逐级翻分类：
设置窗口上方有"查找设置"搜索框 → 点它 → 输入要找的设置名
（如"壁纸""默认浏览器"）→ 下拉出候选列表 → 点最匹配的一项直达页面。

修改设置：
- 开关型：点一下切换，开=蓝色"开"，关=灰色"关"。
- 下拉框：点开 → 在展开列表里点目标项。
- 大多数修改立即生效，没有"确定/保存"按钮，改完看到状态变了就是成功。
- 改完确认一眼当前状态是否符合目标，是就完事，不要来回再点。

回退与导航：窗口左上角"←"返回上一页；win+i 只会切到已开的设置窗口，
不会重开一个。

禁区：
- "更新和安全"里的按钮（检查更新/重置/恢复）绝对不点——会触发系统级变更。
- 不要动"账户"里的登录选项和密码相关项。
- 弹出"你要允许此应用对你的设备进行更改吗"（UAC 深色确认框）：停下，
  这超出你的权限，选"否"并放弃该路径。
