界面结构（自上而下）：功能区（工具栏按钮）→ 地址栏（当前路径）→ 主体区。
主体区分两栏：左侧窄栏=导航栏（快速访问/此电脑等）——**绝对不要点左侧导航栏**，
一点就会跳去别的文件夹；右侧宽栏=文件列表，你的一切操作都在文件列表和功能区进行。

窗口标题=你现在所在的文件夹名。标题不对说明走错了地方：按 alt+left 回上一处，
alt+up 回上一级文件夹。

文件列表阅读：每行一个文件/文件夹，从左到右是 名称、修改日期、类型、大小。
形如 2026-05-03 0:00 的是修改日期文本，不是文件夹名——认名称列，别点日期列。

新建文件夹（可靠做法，二选一）：
A. 点功能区左上方的"新建文件夹"按钮（金色文件夹图标）。
B. 右键文件列表空白处 → 点"新建(W)"→ 右侧展开子菜单 → 点"文件夹(F)"。
成功后列表里出现一个新文件夹，名字"新建文件夹"处于蓝色选中的编辑状态：
直接输入新名字 → enter 提交。如果编辑状态没了（名字不再选中），点一下该文件夹
→ 按 F2 重新进入改名 → 输入 → enter。
注意：新文件夹只需要建一次。看到列表里已有目标名字的文件夹就直接用，别重复建。

移动文件到文件夹：点一下文件名选中 → ctrl+x 剪切 → 双击目标文件夹的名字进入
→ ctrl+v 粘贴 → 确认文件出现在列表里 → alt+up 回上级。
（也可以把文件直接拖到文件夹图标上，但剪切粘贴更稳。）

删除：选中后按 delete 进回收站（危险动作，任务没明说删除就不要删）。

常见弹窗："位置不可用"“找不到项目”等错误框 → 按 enter 关掉，然后回文件列表
继续；它通常意味着你点到了失效的项，换正确目标重来。
