这台机器有中文输入法。打字时会弹出候选栏（一条横条，列着 1.字 2.字 3.字…），
你打的字母先变成拼音，选了候选才真正上屏。

输中文：
打拼音 → 候选栏出现 → 按空格选第 1 个候选，或按数字键 1-9 选对应的字词
→ 字上屏。打错拼音按 backspace 删，或按 esc 清掉整个未上屏的拼音重来。

输英文/文件名/命令（关键纪律）：
1. 先探测模式：打一个字母，看有没有候选栏弹出。
   - 没有候选栏、字母直接上屏 = 英文模式，放心继续输。
   - 弹出候选栏 = 中文模式：先按 esc 清掉刚才的拼音，再按 shift 切到英文，
     然后重新打那个字母确认直接上屏。
2. 文件名、网址、命令、密码框——一律先做这个探测，再正式输入。

shift 键 = 中英文切换开关。按一次切一次，切完无提示，只能靠打字母探测确认。

候选栏的坑：
- 候选栏浮在屏幕上，可能挡住你要看/要点的目标。目标被挡时先 esc 关掉
  候选栏再操作。
- 拼音没上屏就去点别处，可能把半截拼音留在原输入框，回去检查删干净。
- 输完中文按 enter 前，确认候选已上屏（框里是汉字不是带下划线的拼音）。
