# 07 · 后台控制台（锁定）— 自由度的载体

> 版本：v1.0 工程稿 · 编制日期：2026-06-17
> 上游：Jacksky 要求"后台必须达到 AstrBot/MaiBot 同等水平，驾驶舱是画龙点睛的升华"。
> 地位：与 `04_DESIGN_SYSTEM.md`（驾驶舱）并列的**第二张脸**规范。两者共用 04 的设计系统。
> 缘起：04 + P1-W10 只规划了"驾驶舱（presence）"，**漏了"后台（control）"**——而后台才是自由度/易用性的载体，开源后非技术用户没有它根本玩不转。本文件补这个缺口。

---

## 0. 一句话结论（TL;DR）

1. ASTR 的 web 有**两张脸**：**后台 `/admin`（控制台·自由度）** + **驾驶舱 `/`（在场·升华）**。同一个 Next 应用、同一套 04 设计系统、同一套登录。
2. **后台目标 = 对标 AstrBot/MaiBot 的同等水平**（平台/模型/插件/会话/日志/配置全可视化），让用户打开就有成熟控制台的体验，而不是去翻 `.env`。
3. **后台的差异化 = 我们独有的灵魂层模块**（SoulPackage 浏览器 / 记忆 / 情感曲线 / 智囊团+教学 / 训练飞轮 / 声纹语音 / 传承迁移 / SCI 报告）——这些 AstrBot/MaiBot 根本没有，所以我们的后台天然就**超出**它们，而非追平。
4. **驾驶舱不变其志**（04 §1 克制即高级、她是主角）——丰富/旋钮都进后台，驾驶舱继续"退让给她"。
5. 落点主要在 **P6（开源化/易用性）**；当前齿轮设置页（声纹/取景）是后台的**种子**，逐阶段生长。

---

## 1. 两面架构（为什么分两张脸）

| | 后台 `/admin` | 驾驶舱 `/` |
|---|---|---|
| 本质 | 控制台（control panel） | 在场界面（presence） |
| 目的 | **自由度**：把所有旋钮可视化 | **氛围**：让你感到"她在" |
| 信息密度 | 高（表单/表格/图表/日志） | 低（克制，她是主角） |
| 对标 | AstrBot/MaiBot 后台 + 超出 | 无对标（独创的"第一张脸"） |
| 设计法 | 04 设计系统（shadcn/Radix 表单族） | 04 设计系统（情绪光/Live2D/动效） |

**铁律**：丰富归后台，克制归驾驶舱。任何想往驾驶舱塞旋钮的冲动，先问"这是不是该进 /admin"。

## 4. 技术（复用，不另起炉灶）

- **同一个 Next 应用**：`/`=驾驶舱，`/admin/*`=后台。共用 04 设计系统（tokens/动效/主题）。
- **表单族用 shadcn/ui + Radix**（04 §4 已锁定）——表格/弹窗/Tab/表单天生适配后台。
- **数据来源**：全部经 ASTR Core 的 REST（现有 `/v1/*` 扩出 `/v1/admin/*`），SSE 用于实时日志/监控（直连 Core，复用 SSE 直连方案）。
- **鉴权**：后台是 L2（主人）操作面，登录 + 声纹/口令双因素（接 W9）。开源版默认本地 loopback。
- **配置写回**：UI 改的配置写回 `.env`/`routes.yaml`/SoulPackage，**仍以文件为真身**（UI 是文件的视图，呼应"真身/视图"原则）。

## 5. Phase 落点

- **现在（种子）**：驾驶舱齿轮里的声纹/取景就是后台的雏形，别再往驾驶舱加旋钮——新配置一律进"未来 /admin"的心智账上。
- **P2/P3/P4/P5（随子系统生长）**：每落一个子系统（执行层/圆桌/训练/语音传承），其**只读监控/查看**先以最小卡片进后台；编辑能力随后补。
- **P6-W3~W4（后台主体冲刺）**：把 §3.1 parity 模块做齐（平台/模型/插件/会话/日志/设置/向导）——这是开源易用性的硬门槛，对标两家。**QQ 扫码登录进后台**（消灭现在手动扫码的痛点）。
- **P6 设计冲刺**：后台同样过 04 §9 的视觉标准（不是后台就可以丑）。
- **P6-W5**：插件市场遵 06 §5.5 开源生态公民原则（开放联邦、能托管三家生态插件）。

---

## 6. 验收

- **基线（P6-W3~W4 必达）**：非技术用户**不碰任何文件**就能：连平台(扫码)、填 key、选模型、装插件、看日志、改安全开关——即达到 AstrBot/MaiBot 后台同等可用性。
- **差异化（同期）**：§3.2 至少灵魂浏览器 + 记忆 review + 训练曲线 + SCI 报告四个独有模块可见——证明"超出两家"。
- **两面一致**：后台与驾驶舱同主题、同设计语言、一次登录互通；驾驶舱保持克制（没因为有了后台就往驾驶舱塞旋钮）。
