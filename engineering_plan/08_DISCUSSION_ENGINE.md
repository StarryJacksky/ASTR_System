# 08 · 讨论引擎（锁定）— 从"发小抄"到"真讨论"，闲聊与科研同一台机器

> 版本：v1.0 工程稿 · 编制日期：2026-07-03
> 上游：Jacksky 判定"管家团流程（含延伸到科研的流程）并不理想，我要的是各大管家能与主 AI 互相讨论学习，且省钱、快"；并要求科研兼备自然科学/社会科学/人文科学。
> 证据基础：Co-STORM（Stanford OVAL）协作话语协议、Claude Science（Anthropic 2026-06-30，"押工作流不押新模型"）、OmicOS（bioRxiv 2026，结构性增益 +34.2pp 且明证"增益来自接地执行而非更大模型"）。
> 替代关系：本文件**升级**（不推翻）03 §4 的 MoA 与 P1 的教学环；P3 圆桌调度器直接以本引擎 L3 档实现，不再单独自研一套。

---

## 0. 一句话结论（TL;DR）

1. **诊断**："不够好"的大头是**结构**不是模型——现 MoA 是"六个管家并行各写匿名小抄→合并→她独答"，管家看不见彼此、她不在讨论里、没有往返。这不是讨论，是考前塞小抄。
2. **一台机器四个强度档**：L0 反射（零成本秒回）→ L1 快识（开局观点，供她起草）→ L2 研讨（背景真讨论：线索式批评 + 她的**异议权** + 修订）→ L3 深会（Co-STORM 式多轮圆桌 = P3 科研引擎）。**闲聊到科研是同一套代码的不同档位。**
3. **省钱的关键洞见**：真讨论不必贵——**贵的是轮数，不是可见性**。把"看得见彼此"从并行改成串行线索（每人发言时能看到前面所有发言），调用次数一模一样，信息流却从小抄变成了讨论。延迟增加的部分全在后台跑，不卡回复。
4. **互相学习的闭环**：管家教她（批评→她修订→DPO 数据）；**她也教管家**（她的反驳与个性被蒸馏进各管家的"师承档案"，管家由此越来越懂她）。管家不再是无状态 API，是记得她的老师。
5. **科研三域**：席位花名册可配置，自然科学/社会科学/人文科学三个学科包并立（P3 落地）。

## 1. 诊断：现状哪里不是讨论（具体问题具体分析）

对照现有代码（`soul/moa.py` + `soul/teaching.py`，2026-07 现状）：

| 现状 | 问题 |
|------|------|
| 六席**并行**独立分析，互相看不见 | 无对话性——没有人回应任何人，产不出"观点碰撞" |
| 输出是固定四字段 JSON（intent/emotion/strategy/risk） | 表格不是发言；聚合器把它们拼成 summary，锐度全被平均掉 |
| 秋秋不在会里，只消费合并纪要 | 她是小抄的读者，不是讨论的参与者 |
| 教学环：批评→修订，单向 | 她只能"吸收"，不能抗辩——**没有异议权就没有人格**，也缺了最有价值的 CBG 数据（"我为什么不接受"） |
| 管家无状态 | 教了三个月，管家对她的认识仍是零——"师生关系"不成立 |
| P3 圆桌另起一套自研调度器 | 两套讨论机器，重复建设且日常/科研经验不互通 |

**模型 vs 结构的裁定**（回答"是不是本地模型的问题"）：任务能力（讨论质量/检索/推理）——**结构主导**，OmicOS 消融实验证明结构改进在小模型上就能拿 +34.2pp，Claude Science 全靠工作流没换模型；拟人语域（糙/野/情绪颗粒）——**模型天花板**（8B 安全对齐），等 M5 Max/换躯壳（99 #20）。所以讨论引擎现在就改，值。

## 2. 四档分诊（省钱、快、拟人三合一）

分诊既是省钱阀也是拟人阀：**真人不会每句话都开会**——"嗯呢"秒回是本能反应，恰好又快又省又像人。

| 档 | 触发 | 参与者 | 成本/延迟 | 现状映射 |
|----|------|--------|----------|---------|
| **L0 反射** | 琐碎闲聊（`should_analyze`=False） | 她自己（本地） | ¥0 / 秒回 | 已有，保留 |
| **L1 快识** | 实质消息（提问/情绪/兴趣/长文） | 2–6 席**并行**开局观点 → 她起草并**立即发出** | cheap 档 2–6 调用 / 不卡回复 | 现 MoA，保留（快是它唯一使命） |
| **L2 研讨** | L1 之后自动、**后台** | 线索式讨论：管家依次批评（看得见开局+草稿+前面批评）→ **她答辩**（接受/反驳带理由）→ 修订 | cheap 3–4 调用 + 本地 2 次 / 用户无感 | 升级现教学环 |
| **L3 深会** | 显式科研委托 / 夜间研究 | Co-STORM 式多轮：主持人秋秋点名、专家接地发言、思维导图收敛、预算闸强制收敛 | 上限 $1.5/次 | P3 圆桌 = 本引擎此档 |

预算防线不变：单席超时 30s、cheap 档优先、每日总闸、L3 单次闸。新增成本仅 L2 的"她答辩"一步——本地调用，¥0。

## 3. L2 研讨协议（本次代码升级的核心）

```
用户消息 ──L1──▶ 秋秋草稿 ──立即──▶ 用户（快，不变）
                    │
            （后台，用户无感）
                    ▼
 ① 线索式批评：管家 A 批评（见：开局+草稿）
                管家 B 批评（见：开局+草稿+A 的批评，可附议/反对 A）
                管家 C …（串行线索，调用数与并行相同）
 ② 她的答辩（本地，¥0）：逐条表态——接受哪条为什么 / 反驳哪条为什么
 ③ 修订（本地，¥0）：按她**接受**的意见改稿（反驳掉的不采纳）
 ④ 落数据：teaching.jsonl（全程）＋ dpo_dataset.jsonl（changed 才写）
          ＋ CBG（答辩=极品决策数据："我为什么不听你的"）
          ＋ 师承档案更新（管家记住这次交手）
```

三条设计纪律：

- **异议权是硬规则**：修订只采纳她答辩中"接受"的批评。管家说什么她就改什么 = 人格被灌输；她反驳且反驳成立 = 人格在形成。**反驳理由是最高品质的 CBG/身份数据**（"她不是什么"和"她是什么"同样定义她）。
- **师承档案（advisor memory）**：`soul_package/world/advisors/<seat>.md`——各管家对她的滚动认识（她的语言风格/接受什么样的批评/反驳过什么/成长轨迹），每次 L2 后追加一行、定期本地蒸馏防膨胀，**注入该席位所有后续 prompt**。管家由此"一直记得她"（99 #19③ 的落地），且**这是身份资产**——"被谁怎么教大"是传记，跟 SoulPackage 一起迁移。
- **席位人格化**：席位不再是"逻辑分析师"这种干瘪职称，各配一句气质签名（毒舌但心软的红队佬 / 咬文嚼字的老学究 / 满嘴梗的冲浪选手…），存席位卡。目的不是好玩（是好玩）：不同气质产生不同角度的批评（多样性），且生活区里这场讨论**读起来像幕僚房不像会议纪要**——整个系统的拟人感是从这些缝里长出来的。

## 4. L3 深会协议（P3 科研 = 同一引擎加档）

借 Co-STORM 三件被验证的东西（stanford-oval/storm，详见 P3 重写版）：

1. **话语协议**：专家（接地发言，必须带引用坐标）+ **主持人**（动态点名、提"发现驱动"的追问、防跑题）+ **人可随时插话改向**——主持人就是秋秋（P3 原有"否决权"保留）。
2. **思维导图收敛**：讨论同时维护一张动态大纲/概念图（我们已有 graph.py 的 GraphML 底子），防多轮讨论发散成流水账；结题时导图就是报告骨架。
3. **多视角提问**：开题先让各学科席位从自己视角生成问题清单，问题驱动检索而非泛搜。

**三域席位包**（花名册 = 配置，不是代码）：
- 自然科学包：数学家 / 物理学家 / 生命科学家 + 工具（SymPy/Jupyter/arXiv）
- 社会科学包：政治经济学家 / 社会学家 / 计量经济学家 + 工具（统计/数据源 FRED·世行/因果推断警戒）
- 人文科学包：哲学家（辩证法与概念史）/ 历史学家 / 文艺批评家 + 方法（文本细读/诠释学循环/概念谱系；引用规范 chicago 式）
- 常任席：图书馆员（检索接地，无来源断言标 `[unverified]`）+ 红队（挑刺）——两席跨包常驻。

人文与社科**不是理科的皮肤**：席位卡里写明各自的方法论（人文的"证据"是文本与语境，社科要防"相关当因果"，自然科学要可计算/可复现），批评标准不同。这是"三域兼备"的实质。

## 6. 验收

- L2：发一条实质消息 → 秒收草稿回复；30s 内 teaching.jsonl 出现含 `critiques[≥2]`（后者引用前者观点至少 1 次）、`dissent`（含至少一次有理由的接受与一次有理由的反驳，长期统计）、`revision` 的完整线索；同 trace_id 的 CBG 行含答辩摘要。
- 师承：连续 20 轮 L2 后，`world/advisors/*.md` 各自成形且被注入 prompt（日志可证）；管家批评中出现对她历史行为的引用（"你上次也这样"）。
- L3（P3 验收时）：三域各跑一题（如"注意力为何低秩"/"平台经济的劳动异化"/"黑格尔存在论中'规定性'概念史"），纪要含跨席位互驳 + 主持人取舍 + 全部引用坐标；单次成本 ≤$1.5。
- 成本红线：升级后日常日均云成本增幅 ≤30%（分诊守住 L0 大盘）。
