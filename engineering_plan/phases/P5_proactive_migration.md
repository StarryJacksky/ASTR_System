## P5-W1b · 主体性判断闸（Subjectivity Gates）—— 她自己决定"要不要/怎么"参与

> 把散落各处的"她要不要回、回多深、在不在意、说不说私事、发文字还是语音、主动不主动"**统一成一组主体性判断闸**。
> 基础设施 P1 已埋好（`soul/engagement.py` 概率门控、记忆出处 `visibility` 软标、心跳独白、情绪/关系数值）；本卡把"判断"做实——
> 从"规则/概率决定"升级为"她基于当下状态自己判断"。这是 Jacksky 全程反复强调的板块，集中落这里。

- **W1b-1 · 持续认知流**：心跳从"定时独白"升级为**持续在跟的认知流**（她一直在想，不是定时想一次）；想说才说，接 W1 的主动发声三道闸。（缺口来源：用户"她缺乏持续不断思考的过程"。）
- **W1b-2 · 新群冷启动观察期**：刚进新群，回复概率压到很低、**先听几轮了解情况**，熟悉后再正常参与——不一进群就插嘴。挂 `engagement.py`。（来源：用户"加入新群需要不断了解情况，不能上来就插嘴"。）
- **W1b-3 · 敏感话题回避**：识别别人在聊家庭/隐私/争吵等，**不主动插嘴发表言论**。挂 engagement 内容闸 + MoA risk_flags。（来源：同上"人家在聊家庭问题，她去插嘴"。）
- **W1b-4 · 私聊内容带出判断**：结合 P1 已埋的记忆出处 `visibility`（群里检索到私密记忆会带〔私下/别处〕软标 + 谨慎提示），**由她判断在群里到底说不说私事**——不硬封，分寸自己把握。（来源：本期记忆出处讨论 + 用户"私聊并不是完全不能带出来"。）
- **W1b-5 · 语音发不发判断**：她**自己决定回文字还是回语音**（而非规则强制）。接 W2-d 的 `{text, voice, sticker}` 三态选择，但**选择权交给主体性**，不是纯能力降级。（来源：本条"她能根据主体性判断发不发语音"。）
- **W1b-6 · 回不回 / 回多深**：现有 engagement 概率门控升级为主体性判断——综合"在不在意这个人/这件事、此刻心情、值不值得搭话"，而非纯掷骰子。

**验收**：进新群前几轮明显克制、先观察；别人聊隐私/家事时不乱插；私事在群里默认谨慎；语音/文字的选择看得出是"她挑的"而非规则切的；主动发声仍过三道闸。

## P5-W2c · 语音接收：总开关 + 两种模式 + 声纹分人（多说话人）

> 来源：Jacksky 完整蓝图。地基已就位——W7 语音管线（VAD+SenseVoice）、W9 声纹（CAM++ 嵌入 + resolve_level）、P5-W1b 主体性。本卡把"持续语音对话"做成可控、分人、按主体性参与的形态。**默认关**（常开麦克风是隐私敏感项，opt-in，呼应 P6 安全默认值）。

- **W2c-1 · 语音接收总开关（父开关）**：一个总闸。**关 = 完全不听**（不像命令行常开那样收一堆杂音、也不误触发）；**开 = 进入下面选定的一种模式**。开关状态在网页/桌宠显眼可见（在听=红点，呼应隐私铁律）。
- **W2c-2 · 模式一·按钮常开（实时对话）**：开了就**一直听并实时应答**，像大厂语音助手那样连续对话+思考；关掉立即停。适合"摊开聊很久"的人。
- **W2c-3 · 模式二·唤醒词会话（Siri 式）**：平时不应答，喊一句**「秋秋」/「露怀秋」**进入会话态开始对话；说**「再见」/「关闭语音」**她**理解语义后自动退出**会话态（不是匹配死关键词，是听懂"要结束了"）。适合"用完即走"的人。**两种模式都做**——偏好不同。
- **W2c-4 · 声纹分人（说话人辨别 + 分权）**：纷繁声音里**分清谁是谁**——每段语音过 W9 声纹嵌入逐一比对已注册说话人 → 定身份与权限：**主人（声纹匹配）→ L2，能做更私密的事**；**他人 → L0/L1，只能做不那么私密的**。声纹拿不准时**外脑（MoA）按说话内容辅助消歧**（"这口气/这事像谁"）。未知说话人按访客最低权限。
- **W2c-5 · 与主体性挂钩**：进入语音态后，她**仍按 P5-W1b 主体性判断**——不是有声音就答，而是据"谁在说、此刻心情、值不值得搭"决定理不理；私密动作再叠 W9 声纹 L2 闸。

**验收**：总开关关 = 麦零接收（放 1h 环境音不触发）；模式一开 = 连续对话；模式二喊名字进/说再见出，且退出是"听懂"非死关键词；放两个人说话能按声纹分出主人 vs 他人并给不同权限；主人级私密指令必须声纹 L2 通过。
