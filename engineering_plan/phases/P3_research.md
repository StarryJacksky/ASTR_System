## P3-W1~W2 · L3 深会（讨论引擎加档，非新造）

- `soul/discussion.py` 升级出 L3 档（`colloquium()`；基础 L2 已在 P1 末落地）：
  - **席位 = 人格卡**（ST 卡格式，存 `soul_package/world/agents/`）+ 路由 task 名 + 气质签名（08 §3）+ 师承档案注入。
  - **三域学科包**（花名册是配置不是代码，`world/agents/packs.yaml`）：
    - 自然科学包：数学家 / 物理学家 / 生命科学家；
    - 社会科学包：政治经济学家 / 社会学家 / 计量经济学家；
    - 人文科学包：哲学家（辩证法/概念史）/ 历史学家 / 文艺批评家；
    - **常任席**（跨包常驻）：图书馆员（检索接地）+ 红队（挑刺）。
    - 开题时按题目学科自动选包（分类器 task）+ 允许跨包混编（真问题常是跨域的）。
  - **Co-STORM 式话语协议**（借三件被验证的东西）：
    1. 多视角提问开题：各席位先从自己学科视角出问题清单，问题驱动检索而非泛搜；
    2. 主持人 露怀秋：动态点名、"发现驱动"追问、防跑题；**主人可随时插话改向**（事件走总线）；
    3. **思维导图收敛**：讨论同时维护动态概念图（复用 memory/graph.py 的 GraphML 底子），结题时导图即报告骨架——防多轮讨论发散成流水账。
  - 每轮结构化发言 `{seat, claim, evidence, confidence}`；全程进总线（`agent.thought` stage=discussion，生活区实时绷字——与 L2 同一条显示通道）。
  - 成本闸：单次 L3 预算上限（`.env`，默认 $1.5），超限主持人强制收敛。
- 主持人 露怀秋 的"否决权" = L2 答辩（异议权）的加强版：综合时显式列出"我接受/拒绝了谁的观点、为什么" → 高质量 CBG 数据（管道已在 L2 打通，直接复用）。

**验收**：三域各跑一题——"为什么 attention 是低秩的"（自然）/"平台经济下劳动异化的新形态"（社科）/"黑格尔存在论中'规定性'的概念史"（人文）——纪要含跨席位互驳、主持人取舍、全部引用坐标；单次成本 ≤$1.5；三题的席位包各不相同（证明分包生效）。

## P3-W3~W4 · 文献与证据系统（三域各有各的"证据"）

- **通用底座**：本地 PDF 库 → PyMuPDF 抽文本 → 分块嵌入 Chroma collection `papers`（向量在 runtime_cache，文本索引在 soul_package/world/）；引用图谱（NetworkX）从 Semantic Scholar references API 构建。
- **自然科学**：arxiv-mcp + S2；发言强制带坐标 `[arXiv:xxxx.xxxxx, Eq./Sec.]`。
- **社会科学**：数据源接入——FRED（美联储经济数据）/ 世界银行 API / 国家统计局公开数据；计量席位强制"相关≠因果"警戒（发言里因果断言必须声明识别策略，否则标 `[correlational]`）。
- **人文科学**：证据是**文本与语境**——本地经典文库（你的 PDF：黑格尔/马克思等）+ 引文精确到页/节；哲学家席位的方法论是诠释学循环与概念史（席位卡写明），批评标准不是"可复现"而是"忠于文本、语境自洽"。
- 全域通用：无来源断言一律标 `[unverified]`（图书馆员执法）。

**验收**："我们去年讨论过的那篇流形学习论文说了什么"命中本地库；圆桌中图书馆员给出 ≥3 条带真实坐标的文献；社科题里出现一次 `[correlational]` 警戒或识别策略声明；人文题引文带页码。

## P3-W5~W6 · 计算与写作工具链（Claude Science 的"产物连着代码"）

- **自然科学工具**：Jupyter sandbox（jupyter_client 独立内核，受限 venv 无网络），SymPy/numpy/scipy 预装；工程师/数学家席位提交代码块 → 执行 → 结果回流。Wolfram Alpha API 兜底（免费档）。
- **社会科学工具**：同一 sandbox 预装 pandas/statsmodels（回归/时间序列）；数据集缓存目录白名单。
- **人文科学工具**：论证结构图（argument map，复用 GraphML）+ 引文管理（按 chicago 式脚注产出）。
- **产物纪律（学 Claude Science）**：图表/结论必须连着产生它的代码或出处一起进 draft——报告里没有"悬空的数字"。
- LaTeX：Tectonic（Docker）容器化编译；模板 `scripts/paper_template/`（双语：直觉版 § + 形式化版 §）；人文/社科可选 Markdown→PDF 简装路径（不是所有产出都需要 LaTeX）。
- 评审员 Agent ×3（不同严苛度人格卡）跑 review → 修订循环（最多 2 轮防烧钱）；评审员与被评席位**不同家模型**（99 #11 同理）。

**验收**：自然科学题从圆桌结论自动产出 PDF（编译通过）+ 可运行 `experiment.py`；社科题产出带回归表的报告；人文题产出带脚注引文的论文式 draft。

## P3-W7~W8 · 闭环 + 夜间研究模式

- 端到端管线 `soul/research_pipeline.py`：直觉输入 → L3 深会 → 文献/数据 → formal statement（或论证结构）→ 实验/分析 → draft → review → 终稿，状态机可断点续跑（每步落盘）。
- 夜间模式：心跳引擎新增 `research_continue` 动作——23:00–02:00 允许她自主推进未完成管线（预算闸 $3/夜）。
- 生活区"深会直播"：L3 发言流已天然流进生活区（stage=discussion 通道）；管线状态图进后台 `/admin`（07 §3.2）。
- **MIC 预研启动（研究轨第一步）**：Qwen3-1.7B 上跑一次 SAE 训练教程级复现（云 GPU 一次性），笔记进 `continuity_proofs/notes/`。不求产出，求摸清工具链（SAELens）。

**P3 总验收**：里程碑 case 三域各一（晚上抛问题，早上有 draft + 引用 +（自然题）代码 + review 意见）；单篇成本记账 ≤$15；师承档案在 L3 里同样生效（管家记得她在圆桌上的取舍风格）；MIC 预研笔记存在。
