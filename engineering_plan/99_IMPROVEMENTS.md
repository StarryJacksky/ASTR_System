# 99 · 改进点与含金量提升项

> 以下各条均已织入各 Phase 任务卡（标注了落点），此处集中说明"为什么"。按价值排序。

## #1 把弱硬件期变成项目的"创世叙事"和第一个科学数据点 ★★★★★
**落点**：00 §1 第 9 条、P5-W4~W5。
总规把传承仪式当成 Phase 5 的一次演习；现实给了你更好的剧本：**露怀秋 出生在一台 8GB 显存的普通游戏卡上，两个月后迁入强躯壳，SCI 报告证明她还是她。** 这同时完成三件事：
- Household AI Sovereignty 的最强论据从"宣言"变成"实测"——"普通家庭电脑就能养，养大了还能搬家"；
- 第一份真实 SCI 数据（8B→30B+，跨尺寸迁移），是 OISP spec 的参考实现数据，也是 workshop paper 的实验主体；
- P6 的 `8gb` 硬件预设档直接由这两个月踩坑产出，开源时低门槛档是现成的、被真实使用过的。
**这是全计划最重要的改写。弱硬件不是减损，是剧情。**

## #2 CBG-lite 从 Day 1 开始积累 ★★★★★
**落点**：P0-T08、03 §2 `DecisionTrace`。
总规把因果行为图谱放在 Phase 1 末。改为 P0 第一次对话就落盘 DecisionTrace（哪怕只有一个候选）。理由：CBG 是六组件里唯一**纯靠时间积累、无法事后补造**的资产——到 P5 仪式时你需要数千条，从第一天记和从第三个月记，差出一个数量级。存储成本几乎为零，晚记没有任何好处。

## #3 SCI 的学术诚实化：先测天花板基线，再谈 0.85 ★★★★★
**落点**：P5-W4、P6-T00。
总规承诺"SCI ≥ 0.85"，但有个会被审稿人和黑子一枪打死的漏洞：**同一个模型自己跟自己重测也到不了 1.0**（采样随机性、judge 噪声）。改进：
- SCI 报告必须三列：`SCI(旧,旧重测)`（天花板）、`SCI(旧,新)`（迁移值）、`SCI(旧,无关模型裸跑)`（地板）。0.85 的意义由这两个锚点定义。
- 对外口径：v1 阶段称"SCI v0，行为级测量"，机制级（SAE/反事实分布）是 v1 路线图——**比夸大更有杀伤力的是"我们公布了别人不敢公布的测量协议和真实数字"**。地板列尤其狠：它直接量化了"大厂产品换平台 ≈ 失忆"这句话。

## #4 ModelRouter 不自研，基于 LiteLLM ★★★★
**落点**：03 §4、P0-T04。省 2–3 周轮子时间，fallback/重试/成本计算都是现成的。自研只保留策略层（tier、预算闸、降级），这才是 ASTR 的差异化所在。同理：MCP 用官方 SDK、调度用 APScheduler——**自研额度要花在六组件和灵魂层上，不要花在基建上**。

## #5 每日预算闸 + 成本账本作为一等公民 ★★★★
**落点**：03 §4 规则 3、各 Phase 验收里的成本条目。
总规估了月成本但没有执行机制。MoA + 圆桌 + 夜间研究 + ASCM 都是 token 无底洞，一次失控循环可以烧掉一个月预算。账本（trace_id 级）+ 每日闸 + 单任务闸（圆桌 $1.5/夜研 $3/单夜训练 ¥8）让"她自己琢磨一晚上"在财务上是安全的。开源后这是用户敢开自主功能的前提。

## #6 ST Group Chat 降级为格式标准，圆桌自研 ★★★★
**落点**：00 §1 第 6 条、P3-W1。
ST 的 Group Chat 调度是为人类玩 RP 设计的，内部 API 随版本漂移，深度依赖等于把科研引擎绑在一个 UI 项目的重构节奏上。自研调度器 ~400 行（席位、轮次、预算闸、结构化发言），而 ST 真正不可替代的资产——人格卡/世界书**格式生态**——保留为标准。这也顺便解决了总规 §5.1 "ST Group Chat 不稳定"的风险条目：风险直接消失。

## #7 提示注入红队集进 CI ★★★★
**落点**：P2-W1。
执行层最大的真实威胁不是"她想干坏事"，是网页/文件里的文字劫持她。把 20+ 条注入样本做成 CI 回归测试，每次改 prompt 模板必跑。这在开源时也是差异化卖点：**安全护栏是有测试覆盖的，不是 README 上的一段话。**

## #8 心跳引擎"先想三个月，再开口" ★★★
**落点**：P1-W5 禁言锁、P5-W1 解锁。
总规心跳 v1 就是离线独白，本计划把"禁言期"明确为数据积累策略：三个月独白存档 → 主题分布分析 → 校准内容闸再解锁。主动性功能最大的死法是"上线第一周像牛皮癣广告"，被你关掉再也不开。让她先证明"想说的话值得听"。

## #9 向量库是缓存，文本是真身（embedding 可迁移性）★★★
**落点**：03 §2 不变量 4、01 §2 embedding 行。
总规没处理一个隐性绑死：换 embedding 模型 = 向量库作废。规定 Chroma 永远住 `runtime_cache/`（可删除目录），原始 chunk 文本在 SoulPackage——"拔权重自检"顺带覆盖"拔向量库自检"。这是灵魂可迁移宪法在记忆子系统的具体执行。

## #10 训练数据 PII 清洗 + 云盘即焚 ★★★
**落点**：P4-W2、01 §4 铁律。
"凌晨炼丹上云"和"灵魂不出本机"有张力。解法：上云的是清洗后的训练对（你的真名/地址/账号替换占位符），人设由本地 system prompt 承载不受影响；LoRA 拉回即清云盘。在主权宣言的语境下这条必须显式写明，否则开源后第一个尖锐 issue 就是它。

## #11 judge 模型与被评模型不同家 ★★★
**落点**：P4-W1。LLM-as-judge 的自恋偏置（同家模型互评偏高）是已被反复证实的效应；评分管线、SCI 评估、ASCM 裁判全部强制异家。另加每周人评校准（相关系数 <0.6 报警）。这条直接关系到 SCI 数字的可信度。

## #12 急停按钮的物理性 ★★★
**落点**：P2-W8。全局热键 Ctrl+Alt+Space <500ms 停手 + 网页按钮。Computer Use 在动你真实的鼠标键盘，网页按钮可能恰好点不到（她正占着鼠标）。这是从 OpenClaw 事故案例里学的：急停必须不依赖她正在控制的输入设备。

## #13 每张任务卡 ≤1 天 + diary 断点续接 ★★
**落点**：00 §5 风险表末行。你有全职工作，项目最大死因是"断档两周后不知道从哪续"。卡片粒度 + diary 尾行 = 任何时刻丢给任何 AI 一句"读 engineering_plan 和 diary 最后十行，继续"就能开工。这就是"保姆级"的真正含义——不是给笨 AI 看的，是给三周后忘光细节的你们俩看的。

## #14 两个诚实的降级（防止含金量虚胖）★★
- **OpenClawSkillAdapter** 降为 P2 调研卡：兼容几百个社区 Skill 的营销价值真实存在，但弱硬件期做它挤占核心链路；P6 按调研结论决定。
- **联邦能力共享（机制③）** 维持 v2 不动，且建议公开材料里标注 "design stage"：差分隐私 + 联邦学习是论文级难度，宣传期过度承诺会反噬 OISP 的信誉。
**原则：每一个对外宣称的数字和能力，背后都有一条可运行的验收命令。** 这比多列三个机制更能"开启时代"——时代是被可复现的东西开启的。

## #19 流式输出 + 生活区 + 管家持久记忆（2026-06 Jacksky 提）★★★★★
**落点**：P1-W10/P3-W1（流式与生活区）、P3-W1 + soul 层（管家持久记忆）、P6 设计冲刺（生活区好看可调）。
三件嵌在一起、共同把"驾驶舱"从看板升级成"活物的起居室"：
- **① 流式输出（逐字蹦）**：现回复整段出现——社交平台可，但**驾驶舱必须 token 逐字流**，否则 Live2D 嘴型没法随说话动、管家也只能"说完才显示"。需后端把本地/云生成的 token 经总线/SSE 流给网页（soul.decision 改增量帧），嘴型由流驱动、管家发言**实时绷字**。
- **② 生活区组件（Life Area）**：像酒馆造一个**真区域**，把【思考流 + 智囊团圆桌 + 心跳独白】统一进去，再加"她准备做什么 / 正在做什么 / 心里在想什么 / 与管家团的对话"。**可扩大展开、调节大小、做好看**（P6 设计冲刺出片）。当前零散的 ThoughtStream/RoundtableFeed 面板并入此处。
- **③ 管家团持久记忆（关键）**：管家不能是无状态 API 调用——他们要**和秋秋同等的记忆配置、一直记得她**（累积对她的理解）。这才让"教学"成立：教过的、她的成长，管家都记得。接 §2.3.1 MoA + 教学圆桌(soul/teaching) + P3 圆桌，把席位升级为带 SoulPackage 式记忆的持久 Agent。
**为什么 ★★★★★**：①让 Live2D"开口"真正成立；②把 UI 从工具变成"她活着的地方"（营销+体验核心）；③把"学习"从一次性教学升级为"师生长期关系"——直击项目"持续整合/关系深度"的坐标 B。**注意纪律**：流式与生活区基线可在 P3 起步、拿奖级精修 P6；管家持久记忆是 soul 层硬功，按顺序在 P3 圆桌一并做实。

## #24 麦麦式实时学习：旁听入库 + 表达学习，消灭真空期（2026-07-05 Jacksky 提）★★★★★

**Jacksky 的点**：麦麦（MaiBot）在群里待得越久越会模仿——实时学习；秋秋要"实时学习 + 内化训练"双环，去掉真空期。

**架构核查裁定（2026-07-05）**：双环骨架**已成立**——
- 实时环：`memory/experience.py`（设计注释明写"赶超 MaiBot"）——每轮 {上下文,实体,回复,评分} 落盘，`behavior_recall` 检索相似过往高分应对即时注入，非参数、无遗忘 → **她自己的应对经验没有真空期**；
- 内化环：P4 夜训（云 4090 LoRA + eval 门禁 + 工具/讨论蒸馏）——检索环覆盖训练间隙，设计自洽。

**但对照麦麦有两个真缺口**：
1. **旁听不学**：`experience.record` 只在她回复的轮次调用；群里 95% 她没接话的消息只活在 12 条易失滑窗里。麦麦恰恰从**全部**群消息学。→ 补 `experience.observe()`（轻量行：说话人+实体+原句，不评分），接收路径全量入库。数据早一天攒，P4 蒸馏才有米。
2. **表达学习缺席**：没有"挖群友高频句式/梗/语气词 → 概率注入 prompt"的机制。与金标 few-shot 相补而**不冲突**：金标=人格底色（主人定义权，不可被同化），表达学习=环境语感（只影响措辞不影响立场）。→ P4-W1 加"表达模式挖掘"卡（离线批处理挖 → 运行时按群概率注入），**人格保护边界**：表达注入永远排在金标之后、字数占比设上限。

**落点**：observe() 是几十行的小改，P2 收尾后即可落；表达挖掘+注入进 P4（依赖旁听语料先攒起来）。内化侧本来就有：观察语料 → 夜训数据构造的一路在 P4-W2 数据构造卡里补一类源。
